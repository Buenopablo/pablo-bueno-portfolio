# pablo-bueno-portfolio# Pablo Bueno | Portfólio

Portfólio pessoal desenvolvido para apresentar minha trajetória profissional, experiências, habilidades técnicas e projetos na área de desenvolvimento de software.

## Sobre o projeto

Este projeto tem como objetivo centralizar minha apresentação profissional em um único espaço, destacando minha experiência com desenvolvimento Full Stack e Backend, tecnologias utilizadas e projetos desenvolvidos.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Apresentação profissional.
- Seção sobre mim.
- Tecnologias e habilidades.
- Projetos em destaque.
- Experiência profissional.
- Formação acadêmica.

- Layout responsivo.

## Execução local

1. Clone o repositório:

```bash
git clone https://github.com/SEU-USUARIO/pablo-bueno-portfolio.git
```

2. Entre na pasta:

```bash
cd pablo-bueno-portfolio
```

3. Abra o arquivo `index.html` no navegador.
